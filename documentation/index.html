Good work starts here.

Your guide to installing, editing and launching the Velmont stationery & office supplies template.

1. Run locally

Open index.html directly, or use the included Node.js static server. Node.js 18 or later is recommended. 

node scripts/serve.cjs

Visit http://127.0.0.1:4173 . Stop the terminal with Ctrl+C. No installation, build or backend is needed to display any page. Deploy the root folder contents to any static host or GitHub Pages.

All pages contain their header, footer and main content in HTML. Shared components are authored in scripts/build.cjs and emitted into the complete HTML files. Edit the builder for consistent global changes, then run node scripts/build.cjs . Direct HTML changes are supported, but rebuilding overwrites them. No build step is required for hosting.

3. Design customization

Set brand colors, text colors, surface colors, container width and section spacing in assets/css/style.css . Responsive rules live in responsive.css ; theme overrides in dark-mode.css ; direction-specific adjustments in rtl.css .

The original stacked-paper logo and matching favicon are under assets/images/branding/ . Inter is hosted locally with its OFL license. Bootstrap 5 CSS and Lucide icons are hosted locally under assets/vendor/ .

Dark mode & RTL

The initial theme follows the system preference. The header toggles persist explicit choices in localStorage, using aurevia-theme and aurevia-dir . RTL changes layout direction; English is not translated. Storage failures are handled gracefully. Use actual translated copy before launching a localized site.

4. Catalogue & images

Product records are authored in scripts/build.cjs and emitted to assets/js/products.js . The main catalogue shows the first twelve products; additional records support the curated sections. Each record has a stable ID, name, category, indicative USD price, image and description. Details are selected with product-details.html?id=1 . Use the same ID in product links.

The default journal includes three dedicated gallery photographs. Other product selections use their own product image and show generic specifications requiring confirmation. Product photographs are illustrations of catalogue merchandise, not guaranteed supplier specifications.

All 74 content photos are original AI-generated images, created with the built-in image generation tool and optimized locally to WebP. See the image inventory for subjects, page, section, hashes, use and generation prompts. Every file has a distinct SHA-256 hash. The same product may appear in its selected detail view; thumbnail previews intentionally reference the same image within their gallery. No content photograph is shared between separate static page sections.

Replace a photograph by saving a new optimized WebP at its current path. Keep aspect ratios appropriate to the layout and update alt text. Preserve the width/height attributes for loading stability; responsive CSS handles display dimensions.

5. Forms & map integration

Contact, bulk and interest forms are currently unavailable for online submission. They validate required fields and email syntax, then show that nothing was delivered or stored. No email is sent and there is no backend.

To activate production submission, set window.AUREVIA_CONFIG.formEndpoint in assets/js/forms.js to your secure endpoint. The script sends JSON with named fields and a form type. Configure server-side validation, spam protection, retention and appropriate privacy information. Update the submission status only after live integration is verified.

Set mapEmbedUrl to your Google Maps HTTPS embed URL. Until configured, the contact page displays an intentional location placeholder. Replace the demo email, hours and business address with actual details. No real business location is implied.

6. QA & release notes

Browser QA uses installed Chrome via Playwright. The QA report records the actual results for every page, sixteen viewport widths, two themes and two directions. Screenshots are under tests/screenshots/ . Automated checks cover section counts, overflow, text clipping, image loading, local links and key interactions.

Widths: 320, 360, 375, 390, 420, 480, 576, 640, 768, 820, 992, 1024, 1280, 1366, 1440 and 1920 pixels. See reference review notes . All company narrative, prices and testimonials are illustrative and clearly marked where appropriate. No fake countdown, credentials, authentication or dashboard is included.

Before launch: replace demo business copy, connect and test forms, configure your store map, and replace example.com in sitemap.xml and robots.txt . Hosting-specific custom 404 handling must be configured on your chosen host. This delivery is a local static template; no hosting account or live service is configured.
